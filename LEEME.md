The user wants me to create a Rust project for visualizing Dead or Alive 3 (DOA3) characters and Dead or Alive 2 Ultimate (DOA2U) characters, with its textures and animations using native linux player (no web-based tools). With this visualization program, we want to zoom, rotate, move the camera, execute animations, so we want to have a menu to select the character and then, some kind of floating menu to choose the animation type. Having a background switcher could be a must.
